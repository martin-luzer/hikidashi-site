参考が伝わる 5つの理由

REASON01

URLだけでは
「どこが良いか」が伝わらない

だから
良い秒だけをIN と OUT で切り出す
clip_range.loop
// この区間だけがループします
0:000:05 ▶ 0:281:00

参考動画を送っても、相手は頭から見て「どこのこと？」と聞き返します。良いところを IN と OUT で区切っておけば、開いた瞬間にその区間だけがループ。説明の手間がなくなります。

REASON02

1か月前に保存した参考の
「良かった理由」は思い出せない

だから
選んだ理由を1行で残す
memo.txt
結論から入る対談の冒頭0:05–0:28 ・ 冒頭 ・ ★★★★

最初の5秒で結論、そのあと理由を3つ予告

後で見返したとき、何が良かったのか分からない参考は使えません。保存するときに1行だけ理由を書いておけば、何週間たっても、あの数秒の意味まで戻ってきます。

REASON03

集めた参考は
すぐに、ごちゃまぜになる

だから
4つの引き出しに最初から分けておく
drawers/
デザイン 3冒頭 4演出 2ネタ 5

デザイン・冒頭・演出・ネタ。YouTube の参考は、だいたいこの4つに分かれます。タブを押せば、その引き出しの参考だけが残ります。

REASON04

参考資料づくりに
毎回30分かけていられない

だから
ボタン1つでそのまま渡せる資料に
参考資料.md
# 参考資料：来週の企画 ## 冒頭（2） - 5秒で結論を言う冒頭　0:05–0:28 youtube.com/watch?v=…&t=5s 良いところ：最初の5秒で結論 ## デザイン（2） - 数字を左上に置くサムネ　0:00 良いところ：数字だけ黄色
✓ コピーしました

「参考資料をコピー」を押すと、種類ごとに分かれた資料ができあがります。リンクはどれもその秒から開くので、Chatwork・Slack・Notion にそのまま貼れます。

REASON05

参考の分析まで
自分ひとりではやりきれない

だから
AIへのお願いごとコピーできる
request_to_ai.txt
// Claude や ChatGPT に貼るだけ

種類ごとに、参考どうしの共通点を3つずつ挙げてください。冒頭の台本の型、テロップ、サムネの方向を具体的に。

冒頭の型3つテロップの共通点3つサムネの方向3つ

ヒキダシ自体には AI を入れていません。そのかわり、分析のお願い文をつけてコピーできます。AI の利用料がかからないので、月額なしの買い切りにしました。

FLOW

参考が伝わるまでの
流れ

  1. 購入する

    Brain か Tips で購入すると、アプリの URL とライセンスコードが届きます。

  2. ブラウザで開く

    Chrome や Edge で開くだけ。インストールも登録も要りません。

  3. URL を貼る

    見つけた参考動画の URL を貼ります。動画はダウンロードしません。

  4. 良い秒を IN / OUT で区切る

    I と O のキーで区切ると、その区間だけがループします。

  5. 引き出しにしまう

    デザイン・冒頭・演出・ネタから選んで、理由を1行。

  6. 参考資料をコピー

    種類ごとに分かれた資料が、秒数つきのリンクでできあがります。

  7. 1回で伝わる

    貼って渡すだけ。「どこのこと？」がなくなります。

FAQ

よくある質問

動画をダウンロードしますか？

しません。YouTube の動画はリンクと秒数だけを残し、再生は YouTube の公式プレイヤーです。

データはどこに保存されますか？

クリップ・メモ・画像などのライブラリは、お使いのブラウザの中だけに保存します。ヒキダシの作り手のサーバーには送りません（動画の再生・サムネイル・タイトルは YouTube から、文字の書体は Google Fonts から直接読み込みます）。ブラウザのデータを消すと消えるので、アプリの中からときどきバックアップを書き出してください。

Windows でも Mac でも使えますか？

使えます。Chrome や Edge などのブラウザで動きます。

伸びた動画を探す機能はありますか？

ありません。ヒキダシは、見つけた動画を残して渡すための道具です。リサーチの表やツールと一緒に使ってください。

返金はできますか？

デジタル商品のため、お客様のご都合（気が変わった・使わなくなった など）による返金はできません。正しく動かず、サポートで直せない場合は、返金を含めて対応します。購入前のご質問もサポートへどうぞ。
